# Futaのトミカコレクション

タカラトミー公式レギュラー商品No.1〜No.150と、家族が追加する廃盤・限定トミカを一緒に管理するコレクションアプリです。スマートフォンでは2列、広い画面では3列で表示します。

ホーム上部には家族のトミカ写真を置き、中央に白文字で「Futa」「トミカコレクション」を重ねています。写真の下側へやわらかな暗めのグラデーションを加え、文字を読みやすくしています。スマートフォンで早く表示できるよう、オリジナルの `images/futa-tomica-family.jpeg` は残したまま、Web用に1600px幅・約300KBへ最適化した `images/futa-tomica-family-hero.jpeg` を使用しています。写真を変更するときはWeb用画像を差し替えてください。

## 所持数と家族間同期

カードを1回タップすると所持中になり、画像はカラーのまま写真右下に小さな丸チェックが表示されます。2回目以降は1タップごとに1台増えます。カードのリセットボタンは選択したトミカだけを0台にし、「ひとつ戻す」は共有データの直前の操作を取り消します。Undoも家族全員に共有されるため、直前に別の人が行った操作を戻す場合があります。

所持数と登録車両はMySQLのクラウドDBへ保存され、家族が別の端末から変更した内容は数秒ごとに一覧へ反映されます。ブラウザの `localStorage` は一時キャッシュとして使い、クラウド接続時に旧データが残っている端末の所持数を一度だけ共有DBへ統合します。同じ番号の所持数が異なる場合は、大きい方の数を残します。旧版のJSONバックアップも読み込みでき、所持数を共有一覧へ統合できます。

LINE内ブラウザはSafari／Chromeと端末内キャッシュが別ですが、所持状況の正本は共通のクラウドDBです。初回アクセス時は共有状況の読み込み完了まで少しお待ちください。LINE内で接続できない表示が続く場合は、LINEのメニューから「Safariで開く」など外部ブラウザで開いてください。接続が戻ると画面は自動で再取得します。

**公開URLにアクセスできる人は、ログインなしで共有データを閲覧・編集できます。** URLを知る人全員による編集を許可する方式です。URLを不特定多数へ公開しないでください。

## 廃盤・限定トミカなどの追加

タブは「すべて」「現行モデル」「その他」「持っている」の順で、「すべて」が一番左です。「現行モデル」は公式No.1〜150、「その他」は登録車だけ、「持っている」は所持済みの全車、「すべて」は公式車とその他登録車の全件を表示します。「すべて」では個別リセットのゴミ箱アイコンを表示しません。長い車名や所持数の表示はカード幅に合わせて改行します。「その他」タブで「車両を追加」を選び、名前を入力して写真を登録します。スマートフォンでは「カメラで撮る」で撮影するか、「写真を選ぶ」で保存済みの画像を選べます。カメラの表示方法は端末とブラウザにより異なります。JPEG、PNG、WebP、AVIF、HEIC形式で8MB以下の画像を使用できます。追加した車両には番号を割り当てず、公式No.150の後ろに並べます。誤登録した車両は「削除」で一覧から非表示にできますが、保存済みの画像本体はストレージに残ります。

## 公式商品データ

`data/tomica-catalog.json` に全150商品の番号・名前・公式画像URLを保存しています。ブラウザは `data/catalog.js` を通じてこのJSONを読み込むため、商品データの差し替え先はJSON一か所です。画像は公式サイトのURLを参照し、Gitへ商品画像をコピーしていません。

出典: [タカラトミー公式「トミカシリーズ 商品ラインナップ」](https://www.takaratomy.co.jp/products/tomica/lineup/regular/)

公式サイトの掲載内容を更新するときは、プロジェクトのルートで次を実行してください。公式ページの番号帯リンクを巡回し、商品画像の `alt` 属性から番号と名前を、`src` 属性から画像URLを取得してJSONを更新します。同一商品に複数の画像がある場合は先頭画像を代表URLにします。

```bash
python3 scripts/fetch_official_catalog.py
```

## 実行と公開

このアプリは静的なGitHub Pagesだけでは動作しません。家族間同期にはNode.js API、MySQL、Manus Storageが必要です。このプロジェクトではManus管理のサーバー／DBとストレージを利用します。`DATABASE_URL` と `MANUS_API_KEY` はサーバー側でのみ参照し、ブラウザーには公開しません。サーバーと管理DBの機能は一度有効にすると無効へ戻せません。

Manus以外で動かす場合は、Node.js 22.23.4、MySQL互換DB、および `MANUS_API_URL` / `MANUS_API_KEY` と互換性のある画像オブジェクトストレージを用意してください。`.env` や秘密情報をGitHubへアップロードしないでください。依存バージョンは `package-lock.json` に固定し、コンテナは `Dockerfile` から起動します。

## ファイル構成

- `index.html` — 一覧、タブ、同期表示、車両登録ダイアログ
- `styles.css` — スマートフォン向け2列／広い画面の3列表示と状態表現
- `app.js` — クラウド同期、所持数操作、写真登録、バックアップ
- `server.js` — API、DBスキーマ、Manus Storage連携
- `data/tomica-catalog.json` / `data/catalog.js` — 公式商品データと読み込み
- `scripts/fetch_official_catalog.py` — 公式サイトから商品データを再抽出
- `Dockerfile` / `package.json` / `package-lock.json` — サーバー実行環境と固定依存
- `build.sh` — 公開用静的ファイルの `dist/` 生成
- `images/` — アプリアイコンと画像の代替素材
